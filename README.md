# Ninja Runner - Unity

A high-speed 3D ninja runner game built in Unity, featuring stunning visual effects and iconic characters like Sasuke with Susanoo!

## Features
- **Dynamic Sword Trails**: Highly detailed procedural sword slashes (Fibrous Strands, Overlapping crescents) that mimic AAA anime fighters like Ninja Storm 4.
- **Epic VFX**: Fireballs, impact effects, and high-quality shaders.
- **Fast-paced Gameplay**: Dodge, slash, and dash through levels.

## Technical Details
- Built with Unity Engine.
- Custom procedural mesh generation for VFX.

## Setup Instructions
1. Open this project in Unity.
2. Open the main scene located in the `Assets/Scenes` folder.
3. Hit Play to test the mechanics!
